# DevDashboard

A modern, responsive developer dashboard built with **React** and **Tailwind CSS**.

DevDashboard is a frontend project designed to bring common developer tools and productivity features into one clean dashboard. It was built as a practical project to improve my skills with React, component-based architecture, responsive UI, state management, and browser storage.

## ✨ Features

* 📊 **Dashboard** — Overview of your development activity
* 📅 **Calendar** — Add, view, and delete events with localStorage persistence
* ✅ **Tasks** — Task management interface
* 📁 **Projects** — Organize and display development projects
* 📈 **Analytics** — Visual representation of development statistics
* ⚙️ **Settings** — User preferences stored locally
* 📱 **Responsive Design** — Works across desktop and mobile screen sizes
* 🧩 **Reusable Components** — Built with a modular React component structure
* 💾 **Local Storage** — Persistent client-side data for supported features

## 🛠️ Tech Stack

* **React**
* **JavaScript**
* **Tailwind CSS**
* **React Router**
* **Lucide React**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/devdashboard.git
```

### 2. Navigate into the project

```bash
cd devdashboard
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Then open the local URL provided by Vite in your browser.

## 💾 Data Persistence

DevDashboard currently uses **browser localStorage** for features that require data persistence.

This means data is stored locally in the user's browser and does not require a backend or database.

## 🚧 Current Status

DevDashboard is currently a **frontend-focused project**.

Some sections are fully interactive, while other areas currently serve as UI/demo components. Backend functionality, authentication, and database integration may be added in the future.
